# [BACK-03] Implementar el procesamiento de imágenes con OpenCV

## Objetivo
Crear un flujo reutilizable para leer, transformar y generar la imagen procesada del pizarrón.

## Descripción y alcance
Esta actividad pertenece al área de **Backend** de ApuntIA. El responsable deberá revisar primero lo que ya existe en el repositorio y desarrollar o mejorar únicamente lo necesario, coordinando los cambios de interfaz entre equipos.

## Trabajo a realizar
- [ ] Decodificar imagen.
- [ ] Convertir espacios de color cuando corresponda.
- [ ] Aplicar operaciones en orden definido.
- [ ] Separar funciones de procesamiento de rutas http.
- [ ] Guardar o devolver resultado según contrato.
- [ ] Probar imágenes de diferentes dimensiones.

## Criterios de aceptación
- [ ] Se obtiene imagen procesada sin alterar el original.
- [ ] funciones son reutilizables.
- [ ] resultado se puede recuperar desde la API.

## Entregables y evidencias
- Código o documentación incorporados al repositorio mediante una rama y un Pull Request, cuando corresponda.
- Enlace a los commits o Pull Request asociados a este Issue.
- Capturas, resultados de pruebas o ejemplos de solicitudes/respuestas según la actividad.
- Instrucciones breves para que otra persona compruebe el resultado.

## Dependencias y coordinación
BACK-02 para exponerlo por API; las funciones de procesamiento pueden desarrollarse por separado.
