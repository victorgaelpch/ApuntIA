# [FULL-07] Realizar pruebas de integración entre frontend y backend

## Objetivo
Probar que los módulos funcionan juntos y no solo por separado.

## Descripción y alcance
Esta actividad pertenece al área de **Full Stack** de ApuntIA. El responsable deberá revisar primero lo que ya existe en el repositorio y desarrollar o mejorar únicamente lo necesario, coordinando los cambios de interfaz entre equipos.

## Trabajo a realizar
- [ ] Preparar escenarios de imagen válida, inválida, archivo grande, fallo de red, error de procesamiento y reintento.
- [ ] Levantar ambos servicios.
- [ ] Verificar códigos, mensajes, visualización y tiempos.
- [ ] Guardar evidencias reproducibles.

## Criterios de aceptación
- [ ] Casos prioritarios pasan de extremo a extremo.
- [ ] defectos quedan registrados con pasos de reproducción.

- Enlace a los commits o Pull Request asociados a este Issue.
- Capturas, resultados de pruebas o ejemplos de solicitudes/respuestas según la actividad.
- Instrucciones breves para que otra persona compruebe el resultado.
