# [FULL-04] Integrar el frontend con los endpoints de FastAPI

Conectar el cliente preparado en FRONT-05 con los endpoints reales implementados por backend.

Esta actividad pertenece al área de **Full Stack** de ApuntIA. El responsable deberá revisar primero lo que ya existe en el repositorio y desarrollar o mejorar únicamente lo necesario, coordinando los cambios de interfaz entre equipos.

## Trabajo a realizar
- [ ] Configurar url de api y cors cuando aplique.
- [ ] Conectar envío multipart.
- [ ] Recibir respuesta.
- [ ] Gestionar errores de red y http.
- [ ] Comprobar nombres de campos y rutas.
- [ ] Evitar credenciales en código.
- [ ] Documentar cómo ejecutar ambas partes.
