# Bitácoras reales

Un archivo por Issue (`<ID>.md` o `issue-<número>.md`) con las sesiones **efectivas** de trabajo,
en el formato de [PLANTILLA_TICKET.md](../PLANTILLA_TICKET.md). El sincronizador solo las lee para
contar sesiones; nunca las crea, modifica ni borra.

Los Issues anteriores a FULL-29 (FULL-01…24, BACK-01…28, FRONT-01…22) no tienen bitácora de
sesiones: su trabajo consta en los commits y PRs de GitHub, pero sus horas efectivas **no se
registraron** y no se reconstruyen.
